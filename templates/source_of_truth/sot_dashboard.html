What this is full docs ↗

A team knowledge base where GitHub is the database. Every card is a markdown file in your configured repo.

📊 Insights — stats and findings worth quoting later.
🧩 Concepts — explainers of how something works.
📦 Product Info — facts about your own product (capabilities, limits, pricing).
🛠️ How-Tos — step-by-step procedures that use your product.

How to add content: click + Ingest Content, paste a URL / drop a file / paste text. An LLM extracts candidate cards, a dedup judge checks them against existing ones, you review and accept. Teammates can also edit any file directly on GitHub — hit ⟳ Reindex afterwards.
